# Spring Cloud Alibaba 微服务架构（学习索引）

> 本课程沿用 dev-edu《Spring Cloud Alibaba》课程的知识分类与写作风格，并在其已发布内容的基础上做了三件事：**补齐理论篇**（单体问题分析 → 微服务特性 → 实施方法 → 核心组件 → 技术选型）、**展开已完成部分的关键机制**、**续写配置中心 / 网关 / 消息 / 分布式事务 / 服务保障 / 可观测性 / 交付**。共 52 讲，贯穿案例为 `book-microservice` 多模块工程。

> 官方原版仓库已克隆到同级目录 [spring-cloud-master](../spring-cloud-master)（当前更新至第 21 讲，可 `git pull` 持续获取官方更新）。官方内容与本科目在结构与用词上保持一致，可对照学习；本目录是**完整版**，覆盖到生产落地。

## 学习路线

| 阶段 | 内容 | 对应课时 |
| --- | --- | --- |
| 阶段一 认知篇 | 单体之痛 → 微服务特性 → 实施方法 → 核心组件 → 技术选型 → SCA 全景 → 案例设计 | 01 ~ 08 |
| 阶段二 工程篇 | 多模块工程初始化、三大 BOM 版本治理、微服务拆分与接口设计、公共模块建设 | 09 ~ 12 |
| 阶段三 治理篇 | Nacos 部署与集群、服务注册与发现、分级模型、分组、权重与元数据、Nacos API | 13 ~ 21 |
| 阶段四 通信篇 | OpenFeign 声明式调用、拦截器与上下文透传、LoadBalancer 集成、负载均衡算法与自定义策略、可靠性设计 | 22 ~ 30 |
| 阶段五 配置与入口 | Nacos Config 配置中心、隔离共享、动态刷新与灰度、配置治理、Spring Cloud Gateway 与网关鉴权限流 | 31 ~ 38 |
| 阶段六 分布式能力 | RocketMQ 消息驱动、消息可靠性、Seata 分布式事务、Sentinel 服务保障 | 39 ~ 48 |
| 阶段七 可观测与交付 | Micrometer Tracing 链路追踪、日志指标告警、容器化部署、架构演进总结 | 49 ~ 52 |

## 使用建议

1. **每课结构固定**：课程目标 → 回顾与导入 → 原理与实战 → 注意事项 → 小结 → 作业。作业是检验掌握程度的唯一标准，建议先做再对答案。
2. **版本基线**：JDK 17、Spring Boot 3.5.16、Spring Cloud 2025.0.0、Spring Cloud Alibaba 2025.0.0.0、MyBatis-Plus 3.5.17、PostgreSQL 16、Nacos 3.x。版本不对齐是新手最常见的踩坑来源。
3. **代码组织**：所有课时共用 `book-microservice` 工程，第 09 课完成骨架，之后每课在其上演进，不要在每节课新建工程。
4. **前后依赖**：13~21 课（Nacos）→ 22~30 课（远程调用）→ 31~38 课（配置与网关）→ 39~48 课（消息、事务、保障）→ 49~52 课（可观测与交付），跳读会缺少必要上下文。
